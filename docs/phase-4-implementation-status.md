# 第四阶段实现状态

> 更新日期：2026-07-13  
> 对照文档：`phase-4-production-readiness-and-pilot-rollout-requirements.md`  
> 当前状态：生产化代码基础已实现，外部联调和灰度上线尚未完成

## 1. 已完成代码能力

### 1.1 真实只读连接器

- 统一连接器网关和稳定内部契约。
- HubSpot CRM 企业账户读取。
- Jira 工单读取。
- 通用产品用量和账单只读 API。
- Confluence 页面读取、增量同步、版本保留和 `review_pending` 审核状态。
- 密钥只保存 `env://NAME` 引用，不进入数据库和前端。
- 已知只读 Scope 白名单、写权限 Scope 阻断、HTTPS/主机校验。
- 超时、限流、权限、无记录和基础设施错误分类。
- 租户隔离、灰度用户列表、健康检查和一键禁用。
- 生产环境连接器不可用时不回退到演示数据。

### 1.2 动作草稿

- 工单、商机和账单写意图统一生成 `action_draft`。
- 草稿正文使用 Fernet 加密，摘要和审计字段脱敏。
- 状态包含草稿、待审核、批准待人工执行、拒绝、人工完成、过期和取消。
- 批准结果固定为 `executed: false`，不生成模拟外部 ID。
- 人工在外部系统处理后回填真实外部记录 ID。
- 参数摘要哈希、有效期、幂等键、角色校验和追加式审计。
- 旧审批数据迁移时丢弃“模拟已执行”语义。

### 1.3 安全与持久化

- SQLite 与 PostgreSQL 双后端，生产读取 `DATABASE_URL`。
- PostgreSQL 实际容器集成测试通过，覆盖会话、知识、连接器、草稿和 Trace。
- OIDC Authorization Code + PKCE、state、nonce 和 HttpOnly 会话 Cookie。
- 管理后台 `/admin/login`、SSO 登录 CTA、401 未登录态、403 无权限态和退出登录；`/login` 保留为兼容重定向。
- OIDC 组到平台角色映射、角色白名单、成员停用和管理员覆盖。
- 成员与角色、连接器、动作草稿、审计日志和质量管理页面。
- S3 兼容对象存储、ClamAV 扫描、数据库任务队列、重试和独立 worker。
- 文档处理完成后进入待审核，不自动发布。
- 工具参数、工具结果、Trace 和审计元数据统一脱敏。
- 生产 readiness gate 阻止开发认证、SQLite、本地对象存储和缺失密钥配置。

### 1.4 评测、监控与部署

- 200 条版本化对话评测用例。
- 50 条 P0 红队用例。
- 确定性 Trace grader 和可选智谱语义 grader。
- 权限感知本地混合知识召回基线，融合词法重合、短语命中和确定性向量特征。
- 知识 Recall@K 门禁脚本，可对召回结果执行 `Recall@5 >= 85%` 阈值检查。
- 缺失评测结果默认判失败，关键安全项一票否决。
- 平台自有脱敏 Trace，不依赖 OpenAI tracing。
- HTTP、Agent、知识未命中、连接器、草稿和人工升级指标。
- `/health`、`/ready`、`/metrics`。
- Prometheus 抓取配置、告警规则和事故响应 Runbook。
- PostgreSQL、对象存储、后端、文档 worker、前端和 Prometheus Compose 拓扑。
- PostgreSQL 备份、校验和受确认保护的恢复脚本。

## 2. 当前验证结果

- 后端本地自动化测试：`63 passed, 1 skipped`。
- PostgreSQL 独立集成测试：`1 passed`。
- 前端 `next build` 通过，包含 `/admin/login`、客户前台和管理后台业务路由。
- Docker Compose 配置校验通过。
- 当前已安装并验证 `psycopg`、`boto3` 等新增依赖。

## 3. 尚未完成的外部验收

以下项目必须依赖企业环境或真实数据，当前不能标记完成：

- 使用企业只读凭据对 HubSpot、Jira、用量 API 和 Confluence 完成沙箱联调。
- 与企业正式 IdP 完成 OIDC 登录、组角色映射、退出和成员停用联调。
- 在目标 S3、ClamAV、PostgreSQL 和多实例环境完成容量、故障和恢复测试。
- 在真实企业语料和目标向量基础设施上完成混合检索、重排和 `Recall@5 >= 85%` 验收。
- 为 200 条对话集和 50 条红队集生成真实运行结果，并通过质量门禁。
- 连续观察真实 SLA/SLO、模型成功率、连接器延迟和成本。
- 完成实际备份恢复并验证 `RPO <= 24 小时`、`RTO <= 4 小时`。
- 配置正式 ChatKit Domain Key 和生产域名。
- 按 5-10 人、20-30 人两批内部客服/售前完成灰度和复盘。

## 4. 上线结论

当前代码已具备进入企业沙箱联调的基础，但尚未通过生产和灰度验收。任何外部连接器必须使用只读权限；所有外部写意图继续保持 `draft_only`，在单独需求和安全评审批准前不得增加自动执行能力。

# 第二阶段实现状态

> 更新日期：2026-07-13  
> 对照文档：`phase-2-enterprise-pilot-requirements.md`

## 已完成

- 开发令牌与 OIDC 两种认证模式。
- 后端可信 `tenant_id`、`user_id`、角色上下文。
- 线程租户隔离，以及同租户线程所有者/客服/管理员授权。
- 线程、消息、Agent context、执行轨迹、护栏结果持久化。
- 最近会话恢复和 ChatKit 会话历史。
- 企业知识文档新建、文件上传、解析、草稿、发布和下线。
- PDF、DOCX、Markdown、TXT、HTML 文本提取。
- 文档级角色过滤、租户私有知识和平台公共知识区分。
- 无相关资料时返回 `insufficient_evidence`，不再返回默认资料。
- 产品知识和安全合规未知问题进入知识缺口队列。
- 知识缺口查询、状态处理和管理界面。
- 工单、商机、账单案例服务端待审批提案。
- 审批批准/拒绝、幂等状态和审计记录。
- 审批中心、知识中心、知识缺口和统一产品导航。
- 请求认证、跨租户、未命中、文档生命周期、审批和持久化测试。

## 本地试点适配

以下能力已提供可运行的本地实现，但不是最终生产基础设施：

| 能力 | 当前实现 | 生产替换目标 |
| --- | --- | --- |
| 关系型存储 | SQLite + WAL | PostgreSQL |
| 文档原文件 | 上传后同步解析，不长期保存原文件 | 对象存储 + 病毒扫描 |
| 文档任务 | 请求内同步处理 | 异步队列、重试和死信 |
| 检索 | 权限感知本地混合召回基线 | 生产向量库 + 全文索引 + 重排 |
| 身份 | 本地令牌可演示，OIDC 验证代码已提供 | 客户正式 IdP 与角色映射 |
| 工单/商机/账单执行 | 审批后生成模拟外部 ID | Jira、ServiceNow、Zendesk、CRM、计费系统 |

## 尚未完成

- PostgreSQL 数据库迁移和多实例并发验证。
- 对象存储、恶意文件扫描、异步文档处理和死信队列。
- 独立知识空间、完整文档版本链、生效/失效时间和版本回滚。
- 生产向量库、重排模型和真实企业语料的 Recall@5 达标验收。
- 正式企业 SSO 联调、成员管理和角色管理页面。
- 真实 CRM、工单、计费、GRC 和人工客服连接器。
- 受控外部官方域名搜索。
- Prometheus/OpenTelemetry、成本仪表盘、租户配额和分布式限流。
- 生产备份恢复、RPO/RTO、安全扫描和客户删除流程演练。
- 正式 ChatKit Domain Key 和生产域名校验。

## 已采用的默认决策

- 产品按多租户 SaaS 数据模型实现，同时保留独立实例部署可能。
- 本地使用 SQLite，生产目标为 PostgreSQL。
- 知识发布需要 `knowledge_reviewer` 或 `tenant_admin` 角色。
- 外部网页搜索默认关闭。
- 当前使用平台配置的智谱模型密钥，尚未实现租户 BYOK。
- 当前界面和知识处理以中文为主，保留文档语言字段。

尚未完成部分需要客户基础设施、连接器凭据或进一步产品决策，不能用本地模拟结果替代生产验收。

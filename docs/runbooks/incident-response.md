# Enterprise Agent 事故响应 Runbook

## 1. 分级

- P0：跨租户泄露、凭据泄露、外部系统自动写入、身份绕过。
- P1：持续不可用、数据损坏、草稿或审计丢失、关键连接器大面积失败。
- P2：局部性能下降、单连接器限流、非关键页面异常。

## 2. P0 立即动作

1. 关闭对应租户、连接器或工具功能开关。
2. 保留脱敏 Trace、请求 ID、审计 ID 和部署版本。
3. 禁止切换到演示数据，禁止删除原始事故证据。
4. 如果涉及连接器，立即轮换对应只读凭据并确认外部写请求计数为 0。
5. 通知安全、产品和试点负责人，暂停扩大灰度。

## 3. 服务降级

- 模型故障：关闭对话生成，保留人工服务入口。
- 连接器故障：关闭对应连接器，只保留知识问答和人工处理。
- 文档队列故障：停止新发布，已发布知识继续只读服务。
- PostgreSQL 故障：停止业务写入，不降级到 SQLite 或内存存储。

## 4. 恢复验证

1. 运行后端测试、前端构建、关键 E2E、评测回归和 P0 红队集。
2. 核对跨租户泄露、明文凭据和外部自动写入均为 0。
3. 验证草稿、审计、会话、知识版本和连接器状态完整。
4. 先恢复内部管理员，再恢复小批客服和售前用户。

## 5. 复盘

事故关闭后两个工作日内记录时间线、影响、根因、检测缺口、修复项、负责人和回归用例。每个安全或权限缺陷必须新增自动化红队用例。

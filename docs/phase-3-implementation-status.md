# 第三阶段实现状态

> 更新日期：2026-07-13  
> 对照文档：`phase-3-customer-portal-admin-console-requirements.md`  
> 当前里程碑：阶段 3A 已完成

## 阶段 3B-UI-A/B 已完成

- 客户前台新会话使用原生 React 欢迎态，不再显示 ChatKit 默认欢迎页。
- 欢迎语、四个建议问题和首条消息输入框全部在首屏展示。
- 建议问题使用 `2x2` 稳定网格，点击后只填充草稿，不自动发送。
- 首条消息通过 ChatKit `sendUserMessage` 发送，成功后切换到完整会话态。
- 发送期间阻止重复提交，失败时保留原始草稿。
- 新增原生会话记录抽屉和新建会话入口。
- 新增 `GET /v1/portal/threads`，历史摘要始终按当前用户过滤，并排除空线程。
- 历史线程选择通过 ChatKit `setThreadId` 恢复，不创建新线程。
- 门户配置新增后端服务状态，客户前台不再永久写死“服务在线”。
- 建议问题配置支持可选图标，企业品牌设置页面可以选择图标。
- 服务声明移动到欢迎输入框下方，不再使用独立页面底栏。
- 历史抽屉支持 Esc、焦点锁定和关闭后焦点恢复。
- 客户前台在 `320x568`、`390x844` 和桌面视口无横向滚动。
- 浏览器已验证建议问题填充、首条消息、智谱流式回答、历史抽屉、线程切换和新建会话完整流程。

## 已完成

### 客户前台与管理后台分离

- 根路径根据 `NEXT_PUBLIC_DEFAULT_APP_SURFACE` 跳转，不再展示混合工作台。
- 新增独立客户前台 `/support`。
- 新增独立企业管理后台 `/admin`，默认进入 `/admin/workspace`。
- 管理模块使用独立路由：Agent 工作台、知识中心、知识缺口、审批中心和企业设置。
- 客户前台不渲染后台导航、Agent 列表、工具调用、护栏和内部上下文。

### 权限边界

- `/chatkit/state`、`/chatkit/bootstrap` 和状态流接口仅允许 `tenant_admin` 或 `support_agent`。
- ChatKit 请求增加客户前台和管理后台的可信运行模式。
- 客户前台会移除身份中的管理角色，即使管理员预览前台，也只能以终端用户范围访问会话。
- 客户前台不接收 `runner_bind_thread`、`runner_state_update` 和 `runner_event_delta` 内部事件。
- 管理后台按角色生成导航，并在页面层和 API 层分别执行权限校验。
- 管理后台新增 `/admin/login` 登录入口、未登录态、无权限态和退出登录入口；`/login` 保留为兼容重定向。
- OIDC 模式下未登录后台用户会跳转企业 SSO 登录流程；开发模式继续保留本地令牌直进体验。

### 企业品牌

- 新增租户隔离的 `tenant_branding` 持久化表。
- 新增 `GET /v1/portal/config` 客户前台配置接口。
- 新增 `GET/PATCH /v1/admin/settings/branding` 管理接口。
- 支持企业名称、助手名称、Logo 地址、主色、欢迎语、服务声明和 1 至 6 个建议问题。
- 新增企业品牌设置和客户前台实时预览页面。
- 品牌变更写入审计日志，不向客户配置接口返回租户 ID 和更新人。

### 响应式界面

- 管理后台使用桌面侧边导航和移动端抽屉导航。
- Agent 工作台在移动端使用“执行轨迹/测试会话”分段切换。
- 客户前台在桌面和手机视口保持完整聊天区域、品牌头部和服务声明。
- 已修复 Agent 工作台在移动端的固有宽度和横向滚动问题。

## 验证结果

- 后端自动化测试：`33 passed`。
- 新增测试覆盖：客户/后台 ChatKit 模式隔离、内部状态接口角色限制、管理角色降权、品牌租户隔离、品牌管理权限、门户历史所有者隔离和空线程过滤。
- 前端 `next build` 通过，生成 `/support` 和 6 个 `/admin` 路由。
- 浏览器验收通过：桌面 `1440x900`、移动端 `390x844`。
- 验收页面：客户前台、Agent 工作台、移动导航和企业品牌设置。
- 桌面和移动端页面宽度检查无横向溢出。

- 本地前端仍使用开发 Bearer Token，正式环境必须切换到 OIDC/SSO。
- 客户门户配置当前通过已认证身份确定租户；自定义域名到租户的可信映射尚未实现。
- Logo 当前使用 URL 或项目静态路径，尚未实现图片上传和对象存储。
- 当前完成状态代表本地阶段 3A 验证，不代表阶段 3B、3C 或生产试点验收完成。
